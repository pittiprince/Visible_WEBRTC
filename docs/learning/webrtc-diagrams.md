## How to Render

To render these diagrams, you can use PlantUML:

1. Install PlantUML: `brew install plantuml` (on macOS) or download from https://plantuml.com/download
2. Run: `plantuml -tsvg diagram.puml` to generate an SVG diagram.
3. Alternatively, use the online renderer: https://plantuml.com/plantuml
